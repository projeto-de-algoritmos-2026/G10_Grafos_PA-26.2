# Docs

Relatório final, benchmarks e material de apoio do projeto.

- `benchmark/`: comparações empíricas — tempo de execução Dijkstra x Bellman-Ford em [`analise.md`](benchmark/analise.md) (dados brutos, gráfico e metadados de execução) e nós expandidos Dijkstra x A* na malha real em `nos_expandidos.csv` (seção 6.3 do relatório).
- `benchmark/cascata/`: curvas reais de resiliência — [`analise.md`](benchmark/cascata/analise.md), CSV, gráfico e metadados.
- `images/`: capturas reais da interface, incluindo o mapa geográfico atual.
- `rede-mundial.md`: topologia, fontes e metodologia do dataset geográfico.
- `relatorio.md`: relatório final da disciplina (issue #13).
